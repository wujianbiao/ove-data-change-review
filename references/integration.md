# 接入仓库与合并门禁

## Agent入口

在仓库的Agent指令文件加入或按现有机制引用：

```text
新建、更新或合并PR/MR前使用 ove-data-change-review 识别数据影响。
无数据影响可简写；有影响须完成适用校验和当前版本人工确认。
分列强阻塞、建议优化和规模触发，未解除强阻塞不得给通过结论。
```

根据实际Agent安装位置调用，不把个人绝对路径写入共享仓库。保持一份规则来源；仓库若覆盖个人默认JSONB或SQL策略，明确记录适用指令。

## 服务器强制执行

Skill不会自动配置GitHub/GitLab。需要平台支持的受保护分支、必需检查与可信评审；配置与付费能力先核实，实施另需授权。

- 所有PR/MR做影响分类；路径、SQL关键字或作者自报无影响不能单独免审。
- 必要校验验证源/目标/报告/数据版本，分列三级；仅未解除强阻塞阻止通过。缺报告、必要任务失败/跳过或关键证据缺失不能被标成建议绕过。
- 确认来自可信身份，高风险独立评审；代码或相关目标依赖变化后重新绑定。源分支文件中的approved标记不能自证审批。
- 限制直接推送、强推和机器人旁路，MR不能自行降低必需检查；平台能力不足时采用受控人工合并，不宣称不可绕过。
- 使用隔离测试资源，不向不可信变更注入生产凭据或合并权限。没有生产扫描、迁移、清缓存或部署的隐含授权。

启用前用测试PR/MR证明伪分类、伪确认、确认后改动、缺证据和跳过检查均不能绕过，而有效证据/确认可通过。只有真实验证后才声明服务器门禁已启用。
